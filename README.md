# README

Welcome to PalmSim, a field-scale oil palm production model written in Python.

# Getting Started

The easiest way to get started is by having a look at the notebooks in the examples folder.

This can already be done without installing any software, simply by navigating to the folder on GitLab/GitHub.

To run these examples yourself you should install Python 3 and download this folder.

At some point you can also find a useful guide/reference in the documentation folder.

# Install Guide

To get started simply install Python 3 using Anaconda.

Next, download this folder and you are ready to go.
